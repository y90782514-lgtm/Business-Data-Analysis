# 商业数据分析（Business Data Analysis）

> 本仓库是我的数据分析学习与实践作品集，内容持续更新中。

## 仓库说明

本仓库收录两部分内容：

- **教材复现**：将教材中以 Power BI / Excel 实现的案例，迁移为 Python（pandas + matplotlib）实现
- **期末大作业**：数据分析实战项目

详细内容见各子目录说明。

## 目录结构

```
Business-Data-Analysis/
├── README.md          本文件（总览，持续完善中）
├── requirements.txt   Python 依赖清单
├── 教材复现/           教材案例 → Python 迁移（按章节组织）
└── 期末大作业/         数据分析实战项目
```

## 运行环境

- Python 3.12（本地 conda 环境 `data_visualization`）
- 安装依赖：`pip install -r requirements.txt`
